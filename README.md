---

PC Build — Подбор комплектующих для компьютера

Вариант задания: Группа А, номер 1.
Основной сценарий: сборка конфигурации из нескольких частей, подсчет итоговой стоимости.

Как запустить проект:

1. Открой папку проекта в VS Code.
2. Запусти сервер (бэкенд). Для этого в корне проекта есть файл start.bat. Просто дважды кликни по нему, откроется черное окно с запущенным сервером. Не закрывай это окно, пока работаешь с сайтом.
3. Открой сайт (фронтенд). Открой файл index.html через расширение Live Server в VS Code (правой кнопкой мыши по файлу -> Open with Live Server). Сайт откроется в браузере.

Структура базы данных (SQLite, файл pcbuild.db):

Таблица users (Пользователи):

- id: уникальный номер
- username: имя пользователя (от 2 до 12 символов)
- email: почта
- hashed_password: хеш пароля (bcrypt)

Таблица products (Товары):

- id: уникальный номер
- name: название
- brand: бренд
- category: категория
- price: цена
- image: ссылка на картинку
- short_desc: краткое описание
- description: полное описание
- specs: характеристики в формате JSON

Таблица orders (Заказы):

- id: уникальный номер заказа
- user_id: связь с пользователем (users.id)
- product_id: связь с товаром (products.id)
- quantity: количество
- created_at: дата создания

Обработчики API (сервер на FastAPI):

- GET /api/products — получить все товары
- GET /api/products/{id} — получить один товар по ID
- POST /api/register — регистрация нового пользователя
- POST /api/login — вход в аккаунт
- POST /api/forgot-password — восстановление пароля
- POST /api/orders — создание заказа
- GET /api/orders — список всех заказов (для отладки)
- GET /api/my-orders — заказы текущего пользователя

Что уже сделано по практическим работам:

ПР 1 (HTML и CSS):
Сверстано 8 страниц (Главная, Каталог, Товар, Корзина, Сравнение, Контакты, Авторизация, Мои заказы). Используется семантическая разметка, Grid и Flexbox. Сайт полностью адаптивен под мобильные устройства (от 360px). В каталоге 21 товар.

ПР 2 (JavaScript и внешний API):
Добавлены две интерактивные формы (обратная связь на контактах и форма авторизации) с валидацией и выводом ошибок прямо под полями. Каталог фильтруется и сортируется без перезагрузки страницы. Подключен внешний API Nominatim (OpenStreetMap) через fetch для отображения карты магазина с индикатором загрузки и обработкой ошибок сети.

ПР 3 (Сервер и база данных):
Написан сервер на Python + FastAPI. База данных SQLite из трех связанных таблиц. Пароли хранятся в виде хеша bcrypt. Все SQL-запросы параметризованы. Страница "Мои заказы" доступна только авторизованным пользователям.
